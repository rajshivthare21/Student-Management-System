# Student Management System (Java + MySQL)

## Description
This is a Student Management System developed using Java and MySQL. The application allows users to perform CRUD operations such as adding, updating, deleting, and viewing student records.

## Features
- Add new student
- View student details
- Update student information
- Delete student records
- Search and sort students

## Tech Stack
- Java
- MySQL
- JDBC

## How to Run
1. Clone the repository:
   git clone https://github.com/rajshivthare21/Student-Management-System.git

2. Import student_data.sql into MySQL

3. Update database credentials in dbConnect file

4. Run the project using any Java IDE
